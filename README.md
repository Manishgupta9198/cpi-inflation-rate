# CPI Inflation Rate Analysis

## 📊 Project Overview

This project analyzes Consumer Price Index (CPI) data to understand inflation trends across different categories in India.

The analysis uses Excel and Power Query for data cleaning and transformation, followed by statistical analysis to identify inflation patterns and examine the relationship between CPI categories and crude oil prices.

## 🎯 Objectives

- Analyze CPI inflation trends over time.
- Study inflation across different categories.
- Calculate Month-over-Month (MoM) percentage changes.
- Identify minimum, maximum, and average CPI values.
- Analyze the relationship between CPI categories and crude oil prices.
- Identify categories with stronger and weaker correlations with crude oil price movements.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Statistical Analysis
- Pivot Tables
- Data Cleaning
- Data Transformation
- Correlation Analysis

## 🔄 Data Preparation

The data was cleaned and transformed using Excel and Power Query.

Main steps included:

1. Cleaning the CPI dataset.
2. Organizing CPI data by year and month.
3. Preparing category-level CPI data.
4. Calculating Month-over-Month (MoM) percentage changes.
5. Preparing crude oil price data.
6. Combining relevant datasets for statistical analysis.

## 📈 Analysis Performed

### 1. CPI Trend Analysis

Analyzed the movement of the General CPI Index over time to understand overall inflation trends.

### 2. Category-Level Analysis

Analyzed CPI categories to identify differences in inflation behavior across food and other major categories.

### 3. Month-over-Month Change

Calculated MoM percentage changes to measure how CPI values changed from one month to the next.

### 4. Statistical Analysis

Calculated:

- Average
- Minimum
- Maximum
- Percentage Change
- Correlation

### 5. CPI and Crude Oil Correlation

Correlation analysis was performed to examine the relationship between CPI category movements and crude oil price movements.

The correlation results were ranked to identify categories with relatively stronger and weaker relationships with crude oil prices.

## 📊 Key Findings

The analysis identified different levels of relationships between CPI categories and crude oil price movements.

Some CPI categories showed positive correlation, while others showed negative correlation. This indicates that different categories respond differently to changes in crude oil prices.

The analysis also helped identify category-level inflation patterns and overall CPI trends.
